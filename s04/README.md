## 동선 가독성 안

Decision #2(구간색+화살표) **보강** — 폐기 아님 (S04-28).

- **A(채택):** 선 굵기↓ (stroke ~1.1–1.4), 화살표 marker 축소(markerWidth/Height ~3), underlay 아주 얇은 대시, 셰브론은 더 작게 또는 개수↓ — 핀·구간색은 유지
- **B:** 실선 유지 + 화살표만 축소, 셰브론 제거
- **C:** 전 구간 짧은 대시(stroke-dasharray) + 소형 화살표, 색 순환 유지

현재 퍼블은 **A** 적용 (얇은 `route-seg` · 소형 marker · dashed underlay · 셰브론 1개/구간).

### 스팟목록 가져오기(Google) — S04-25/26
- CTA: **스팟목록 가져오기(Google)**
- 필드: **구글 저장목록 공유링크** → resolve 후 **체크박스 리스트**
- 기본 자동체크 = `max(0, 25 − N)` · **전체선택** / **전체해제**
- 잔여 쿼터 안내 (스팟목록만) · CTA **선택 항목 가져오기** · 25 초과 시 차단+알람

### 후보스팟목록에서 가져오기 — S04-27
- **체크박스** 목록 · **기본 자동체크 없음** · 전체선택/전체해제
- CTA: **선택 항목 보드에 추가** · 25 초과 차단+알람 (잔여 자동체크 카피 없음)

### 썸네일 선택 팝업 — S04-5 · S04-23/24
- `photoUrls` 목록 선택 + 업로드 드롭존

- 필드명 라벨/주석에 명시

### 스팟 등록 / 후보스팟 등록
- 등록 대상 토글: 스팟(Day) | 후보스팟
- 라디오: **A) 위도·경도로 등록** / **B) 구글맵 공유링크로 등록**
