# S04 맵보드 — 정적 퍼블 프로토타입

시안·퍼블 방향 v0.1 + 파트리더 피드백 반영 정적 HTML/CSS/최소 JS.

## 열기

브라우저에서 `index.html`을 직접 열면 됩니다.

```bash
cd /workspace/travel-planner-dp/s04-pub
python3 -m http.server 8080
# → http://localhost:8080
```

## 확인 포인트

| 뷰포트 | 기대 |
|--------|------|
| **&lt;900px** | 세그먼트 `맵 \| 보드`, **기본 보드**. 맵 탭 시 풀폭 맵 + 하단 피크 시트 |
| **≥900px** | 맵 **60%** / 보드 **40%** 스플릿 + 시각적 스플리터. 세그먼트·피크 시트 숨김 |

### 피드백 반영 (이번)

- **후보지 추가** → 화면 이동 대신 **팝업/모달** (보드 헤더·힌트 버튼)
- 모달 **딤(backdrop)** 명확화 (반투명 오버레이 + 중앙 다이얼로그)
- 스팟 **썸네일 클릭** → **아이콘/이미지 선택 팝업** (아이콘 그리드 + 업로드 드롭존)
- 카드 **되돌리기** → 스팟 → 후보지로 되돌림 (데모 토스트 + 카드/핀 숨김)
- 화면 라벨 **S04 맵보드**

- 핀 ↔ 카드 클릭 시 동일 번호·Accent 하이라이트 동기
- 하단 고정 라벨/스티커 팔레트 샘플
