시안·퍼블 방향 + **수락기준_MVP_v0.8** 맵보드 UX 반영. Korean UI. 와이어/로파이 아님.

## 열기

```bash
cd /workspace/travel-planner-dp/s04-pub
python3 -m http.server 8080
# → http://localhost:8080
```

## 브레이크포인트

| 뷰포트 | 기대 |
|--------|------|
| **&lt;900px** | 세그먼트 `맵 \| 보드`, **기본 보드**. 맵 탭 시 풀폭 맵 + 하단 피크 시트 |

## 데모 포인트 (v0.8)

### 비주얼
- Pretendard · teal/coral 토큰 · 밀도 있는 카드/헤더 (D&P S04 퍼블 베이스)
- 맵 플레이스홀더(지형·공원·수면 틴트)
- **구간색 순환**(최대 8색) + **방향 화살표/쉐브론** · 번호 핀 · 핀↔카드 동기

### 「장소목록가져오기」 → 목록 추가 팝업
- CTA: **장소목록가져오기**
- 필드: **구글 저장목록 공유링크**
- 액션: **가져오기** / **취소** (정적 토스트 데모)

### 스팟 등록 / 후보스팟 등록
- 등록 대상 토글: 스팟(Day) | 후보스팟 (저장 대상만 다름)
- 라디오: **A) 위도·경도로 등록** / **B) 구글맵 공유링크로 등록**
- A: 이름 · 위도 · 경도 → CTA **좌표 등록**
- B: 공유링크 (+이름 선택) → CTA **링크 등록**

### 유지 동작
- **후보스팟에서 추가** 팝업 · **예약연결**(연결됨→상세 / 미연결→목록) · 아이콘 선택 · 되돌리기→후보스팟
- 카피: **후보스팟**만 사용
