# S04 맵보드 — 정적 퍼블 프로토타입 (v0.6)

시안·퍼블 방향 + 파트리더 피드백 반영 정적 HTML/CSS/최소 JS. Korean UI.

## 열기

브라우저에서 `index.html`을 직접 열면 됩니다.

```bash
cd /workspace/travel-planner-dp/s04-pub
python3 -m http.server 8080
# → http://localhost:8080
```

## 확인 포인트

| 뷰포트 | 기대 |
|--------|------|
| **&lt;900px** | 세그먼트 `맵 \| 보드`, **기본 보드**. 맵 탭 시 풀폭 맵 + 하단 피크 시트 |
| **≥900px** | 맵 **60%** / 보드 **40%** 스플릿 + 시각적 스플리터. 세그먼트·피크 시트 숨김 |

### v0.6

- **모든** 스팟 카드에 **예약연결** 링크 (연결됨→예약 상세 / 미연결→목록 선택, v0.5 분기 유지)
- 보드 헤더·힌트에 **스팟 추가** + **후보지에서 추가** 둘 다 노출
- 스팟 추가 = 신규 정적 폼 모달 · 후보지에서 추가 = 기존 후보 선택 모달 (S07 페이지 자체는 미변경)

### 이전 피드백 요약

- 후보지 추가는 화면 이동 대신 **팝업/모달**
- 스팟 썸네일 → 아이콘/이미지 선택 · 카드 **되돌리기** → 후보지
- 핀 ↔ 카드 하이라이트 동기 · 라벨/스티커 팔레트
- **예약연결** ≠ **예약관리**(S06 내역)
